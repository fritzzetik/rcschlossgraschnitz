# Reitclub Schloss Graschnitz

Statische Vereinswebsite mit lokal gespeicherten Bildern und Schriften.

## Website ansehen

`webseite/index.html` im Browser öffnen. Der Ordner `images` muss daneben bleiben. Die Website funktioniert auch ohne Internet; externe Medien- und Facebook-Links benötigen eine Internetverbindung.

Für die Veröffentlichung den Inhalt von `webseite` auf einen statischen Webserver übertragen. Es sind kein CMS, keine Datenbank, kein Node.js und kein Build-Schritt erforderlich.

## Ordner

- `webseite/`: fertige Website einschließlich aller benötigten Bilder.
- `design/GRUNDLAGEN.md`: Vorgaben, gestalterische Annahmen und technische Entscheidungen.
- `design/QUELLEN.md`: Herkunft von Inhalten und Bildern sowie verlinkte Medienbeiträge.
- `design/WEITERENTWICKLUNG-JUGEND.md`: jüngerer Einstieg, Bildauswahl und Kontaktweg.
- `design/UX-OPTIMIERUNGEN.md`: Lesbarkeit, Handybedienung, vereinfachte Vereinsberichte und ausgewähltes Startfoto.
- `design/OFFENE-PUNKTE.md`: fachlich noch zu bestätigende Angaben und Aufgaben vor dem offiziellen Vereinsbetrieb.

## Änderungen

Die auslieferbare Website wird direkt in `webseite/index.html` bearbeitet. Gestaltung und kleines Interaktionsskript sind in dieser Datei enthalten. Bilder liegen unter `webseite/images/`. Nach einer Änderung die betroffene Seite im Browser und auf schmaler Bildschirmbreite prüfen.

Die Seite lädt keine Facebook-Beiträge oder Presseartikel automatisch nach. Neuigkeiten und Termine werden redaktionell von Hand aktualisiert.
